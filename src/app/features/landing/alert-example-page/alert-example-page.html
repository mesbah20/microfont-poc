SwiftFusion Component Library

A comprehensive collection of reusable Angular components with Material Design integration. Each component is fully documented with usage examples and configuration options.

Alert & Modal Components

Success Modal

Displays success messages with green styling and checkmark icon. Used for confirming successful operations, form submissions, or positive user actions. Includes customizable title, message, and button text.

Usage:

<app-alert-success [isOpen]="isSuccessModalOpen" [title]="'Success!'" [message]="message" (close)="closeModal()"></app-alert-success>

Features:

  • • Green color scheme with checkmark icon
  • • Customizable title and message
  • • Responsive design
  • • Keyboard accessibility (ESC to close)
  • • Event handling for close actions

Error Modal

Displays error messages with red styling and exclamation icon. Used for showing validation errors, API failures, or critical issues that require user attention.

Usage:

<app-alert-error [isOpen]="isErrorModalOpen" [title]="'Error!'" [message]="errorMessage" (close)="closeModal()"></app-alert-error>

Features:

  • • Red color scheme with warning icon
  • • Error message formatting
  • • Retry action support
  • • Detailed error information display
  • • Accessibility compliant

Warning Modal

Displays warning messages with yellow styling and triangle icon. Used for cautionary messages, confirmation dialogs, or important notices that require user acknowledgment.

Usage:

<app-alert-warning [isOpen]="isWarningModalOpen" [title]="'Warning!'" [message]="warningMessage" (close)="closeModal()"></app-alert-warning>

Features:

  • • Yellow color scheme with warning icon
  • • Confirmation dialog support
  • • Action buttons (Proceed/Cancel)
  • • Customizable warning levels
  • • User acknowledgment tracking

Info Modal

Displays informational messages with blue styling and info icon. Used for helpful tips, feature announcements, or general information that enhances user experience.

Usage:

<app-alert-info [isOpen]="isInfoModalOpen" [title]="'Information'" [message]="infoMessage" (close)="closeModal()"></app-alert-info>

Features:

  • • Blue color scheme with info icon
  • • Rich text content support
  • • Link embedding capability
  • • Dismissible notifications
  • • Auto-hide timer option

Delete Confirmation Modal

Displays delete confirmation messages with red styling and delete icon. Used for confirming destructive actions like deleting records, files, or account data.

Usage:

<app-delete-confirmation-dialogue [isOpen]="isDeleteModalOpen" [title]="'Delete Confirmation'" [message]="deleteMessage" (close)="closeModal()"></app-delete-confirmation-dialogue>

Features:

  • • Red color scheme with delete icon
  • • Two-step confirmation process
  • • Irreversible action warning
  • • Cancel/Confirm button options
  • • Keyboard shortcut prevention

Data Selection Modal

Advanced modal for selecting data from master tables with search, filtering, sorting, and pagination. Built with Material Design components for consistent UI/UX across the application.

Usage:

<app-data-selection-modal [isOpen]="isDataModalOpen" [config]="dataConfig" (result)="onDataSelected($event)"></app-data-selection-modal>

Features:

  • • Material Design table with sorting
  • • Advanced search and filtering
  • • Pagination with configurable page sizes
  • • Multi-select with checkboxes
  • • Responsive design for mobile/desktop
  • • Error handling with fallback data
  • • Loading states and progress indicators
  • • Keyboard navigation support

Form Components

Text Area Component

Enhanced text area component with character counting, validation, and responsive design. Supports form integration, placeholder text, and custom styling.

Usage:

<lds-txt-area [frmGroup]="frmGroup" [controlName]="'description'" [labelText]="'Description'" [maxLen]="500" [rows]="3"></lds-txt-area>

Features:

  • • Character count display
  • • Maximum length validation
  • • Form control integration
  • • Responsive design
  • • Custom placeholder support
  • • Validation error display

Label Component

Flexible label component for form fields, sections, or standalone text display. Supports dynamic content, visibility control, and custom styling.

Usage:

<lds-label [labelValue]="'Field Label'" [visible]="true"></lds-label>

Features:

  • • Dynamic label content
  • • Visibility control
  • • Custom styling support
  • • Accessibility compliant
  • • Form field association

Switch Component

Toggle switch component for boolean values with smooth animations and form integration. Perfect for settings, preferences, and feature toggles.

Usage:

<lds-switch [frmGroup]="frmGroup" [controlName]="'notifications'" [labelText]="'Enable Notifications'"></lds-switch>

Features:

  • • Smooth toggle animation
  • • Form control integration
  • • Custom label support
  • • Accessibility features
  • • Event handling
  • • Visual feedback

Amount to Word Input

Specialized input component for currency amounts with automatic word conversion. Includes validation, formatting, and localization support.

Usage:

<app-amount-to-word-input [frmGroup]="frmGroup" [controlName]="'amount'" [label]="'Amount'"></app-amount-to-word-input>

Features:

  • • Currency formatting
  • • Word conversion display
  • • Validation rules
  • • Localization support
  • • Read-only mode
  • • Custom currency symbols
